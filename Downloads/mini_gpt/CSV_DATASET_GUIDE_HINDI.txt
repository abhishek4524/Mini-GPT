⚡ STEP-BY-STEP PROCESS (4 Easy Steps)
================================================================================

STEP 1️⃣: CSV को Text Format में Convert करें
───────────────────────────────────────────────

Command:
  python convert_csv_to_text.py

फिर:
  Option चुनें: 2 (Multiple files combine करने के लिए)
  
  Files enter करें:
    C:\Users\user\Downloads\mini_gpt\train.csv
    C:\Users\user\Downloads\mini_gpt\validation.csv
    (Enter दबाएँ)
  
  Output file name:
    combined_data.txt
    (या Enter दबाएँ default के लिए)

Result: ✅ combined_data.txt बन जाएगी
         (~5-10 MB)
         डায़ाग्राम format में:
         User: hello
         Bot: hi there!
         
         User: ...

================================================================================

STEP 2️⃣: Data को Clean और Balance करें
──────────────────────────────────────────

Command:
  python preprocess_data.py

फिर:
  Option चुनें: 1 (Clean and validate)
  
  Input file:
    combined_data.txt
  
  Output file:
    press Enter (default: processed_clean.txt)

Result: ✅ processed_clean.txt बन जाएगी
         - सभी bad messages हटा दिए जाएँगे
         - Duplicates remove होंगे
         - valid data ही रहेगा

================================================================================

STEP 3️⃣: Processed Data को data.txt में Copy करें
─────────────────────────────────────────────────

Command:
  copy processed_clean.txt data.txt

या PowerShell में:
  Copy-Item processed_clean.txt data.txt

Result: ✅ अब data.txt update हो गई है!

================================================================================
⚙️ कुछ CONFIGURATION TIPS
================================================================================

अगर Training बहुत slow है:
  train.py में लिखें:
    USE_MIXED_PRECISION = True  (पहले से है, लेकिन यह faster है)

अगर CUDA out of memory आए:
  train.py में लिखें:
    BATCH_SIZE = 64         (from 128)
    BLOCK_SIZE = 64         (from 128)

अगर बहुत better results चाहिए:
  train.py में लिखें:
    EPOCHS = 20000          (from 10000)
    LEARNING_RATE = 0.0001  (from 0.0005, but slower)

================================================================================
🐛 Common Issues और Solutions
================================================================================

Issue: "No module named 'pandas'"
Fix:   pip install pandas

Issue: Files नहीं मिल रहीं
Fix:   Make sure CSV files सही path में हैं
       C:\Users\user\Downloads\mini_gpt\ में होने चाहिए

Issue: "ValueError: could not convert string to float"
Fix:   CSV format सही है? dialog column है?
       convert_csv_to_text.py automatically handle करेगा

Issue: CUDA out of memory
Fix:   BATCH_SIZE = 64
       BLOCK_SIZE = 64
       दोनों reduce करें

Issue: Training बहुत slow है
Fix:   USE_MIXED_PRECISION = True रखें train.py में
       GPU का use हो रहा है check करें: nvidia-smi
