┌─ STEP 1: Convert CSV to Text ────────────────────────────────────────────┐
│                                                                            │
│  Command:                                                                 │
│    python convert_csv_to_text.py                                         │
│                                                                            │
│  Select: 2 (Combine multiple files)                                      │
│  Add files: train.csv, validation.csv                                    │
│  Output: combined_data.txt                                               │
│                                                                            │
│  Result: User: ...                                                        │
│          Bot: ...                                                         │
│          format में file बन जाएगी                                         │
└────────────────────────────────────────────────────────────────────────────┘

┌─ STEP 2: Clean Data ─────────────────────────────────────────────────────┐
│                                                                            │
│  Command:                                                                 │
│    python preprocess_data.py                                             │
│                                                                            │
│  Select: 1 (Clean and validate)                                          │
│  Input: combined_data.txt                                                │
│  Output: processed_clean.txt                                             │
│                                                                            │
│  Result: Bad messages remove, duplicates delete, valid data ✅            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ STEP 3: Update Training Data ───────────────────────────────────────────┐
│                                                                            │
│  Command:                                                                 │
│    Copy-Item processed_clean.txt data.txt                                │
│                                                                            │
│  Result: data.txt update ✅                                              │
└────────────────────────────────────────────────────────────────────────────┘

┌─ STEP 4: Train Model ────────────────────────────────────────────────────┐
│                                                                            │
│  Command:                                                                 │
│    python train.py                                                       │
│                                                                            │
│  Time: 30-60 minutes (RTX 3050)                                          │
│  Result: mini_gpt_model.pt ✅                                            │
│          आपका model trained हो जाएगा!                                   │
└────────────────────────────────────────────────────────────────────────────┘
