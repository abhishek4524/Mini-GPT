🔧 CONFIGURATION TIPS
================================================================================

For LARGER BATCH SIZE (if GPU can handle it):
  BATCH_SIZE = 256
  (Requires 8GB+ VRAM)

For FASTER TRAINING:
  USE_MIXED_PRECISION = True
  (15-30% speed improvement)

For BETTER QUALITY (takes longer):
  EPOCHS = 20000
  BLOCK_SIZE = 256
  d_model = 512

For LIMITED VRAM (6GB GPU):
  BATCH_SIZE = 64
  BLOCK_SIZE = 64
  (Current defaults work well)

================================================================================
⚠️  COMMON ISSUES & FIXES
================================================================================

CUDA Out of Memory:
  → Reduce BATCH_SIZE to 64
  → Reduce BLOCK_SIZE to 64

Loss not decreasing:
  → Learning rate might be too high/low
  → Use learning rate scheduler (included!)
  → Train longer (at least 5000 epochs)

Poor generation quality:
  → Need more training data (use DailyDialog!)
  → Train for more epochs
  → Increase model size

Old checkpoints conflict:
  → Delete old .pt files
  → Start fresh training with new data

Port 8000 already in use:
  → Use different port: uvicorn app:app --port 8001
